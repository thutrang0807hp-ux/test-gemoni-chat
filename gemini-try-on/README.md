# Gemini Thử Đồ

Ứng dụng Windows riêng để viết prompt thay đồ và thử chỉnh ảnh trực tiếp bằng Gemini Chat. [Tải bộ cài](https://github.com/thutrang0807hp-ux/test-gemoni-chat/releases/download/gemini-thu-do-v0.1.0/Gemini-Thu-Do-Setup.exe).

1. Bấm **Kết nối Gemini** và đăng nhập trên trang Google trong hồ sơ Chrome riêng do app mở.
2. Chọn **Ảnh người mẫu** và **Ảnh bộ đồ**, nhập yêu cầu chỉnh ảnh. Có thể bấm **Gemini viết lại prompt** trước.
3. Bấm **Tạo ảnh bằng Gemini**, rồi **Lưu ảnh** khi ảnh hiện. Lượt tiếp theo dùng nội dung hiện tại trong ô prompt.
4. Khi tác vụ đang chạy, có thể thu nhỏ Chrome riêng và đóng cửa sổ app xuống khay hệ thống. Hồ sơ Chrome riêng cần tiếp tục chạy.

App này có bộ cài và thư mục dữ liệu riêng tại `%LOCALAPPDATA%\GeminiThuDo`. Chrome cần được cài trên PC. Không cần extension, API key hay nhập cookie. Tính năng phụ thuộc vào giao diện Gemini Chat và quyền chỉnh ảnh của tài khoản. Đây là bản thử tích hợp. Luồng Flow và kịch bản không nằm trong bản này.
